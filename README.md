# tett23

- [Golem](https://tett23.github.io/golem/) — コマンドラインと CI で動く組版システム。同じ入力から同じバイト列の PDF を組む。
- [Aleph](https://tett23.github.io/aleph/) — 本と PDF をつくることに特化した執筆・組版環境。
- [peg-hs](https://tett23.github.io/peg-hs/) — Haskell parsers from PEG grammars, with left recursion as written.
- [NablaSKK](https://tett23.github.io/nablaskk/) — AquaSKK の入力エンジンを Rust で再実装した macOS の SKK。
